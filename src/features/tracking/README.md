# Tracking (placeholder)

Watch statuses, the watchlist and 5-star ratings. Per-user data that loads in the browser on public pages.

## Statuses

An anime has at most one status per user:

- Watched
- Watching
- On hold
- Dropped

## Watchlist

The watchlist is a separate toggle, like on Letterboxd, not a status. It is stored and changed independently of the status.
